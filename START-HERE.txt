SUPABASE
--------
1. Create/open a Supabase project.
2. SQL Editor -> run: supabase/01_schema.sql
3. SQL Editor -> run: supabase/02_migrate_current_data.sql
4. Copy Project URL.
5. Copy the server-side Secret key (sb_secret_...).

VERCEL
------
Add these Environment Variables:

SUPABASE_URL = your Supabase Project URL
SUPABASE_SECRET_KEY = your sb_secret_... server key
SESSION_SECRET = random secret, at least 32 characters

Then deploy this whole folder to Vercel.
